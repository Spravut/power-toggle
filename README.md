# power-toggle

Переключатель схемы питания Windows одним кликом по ярлыку на рабочем столе.

| Режим | Экран | Сон | Крышка |
|---|---|---|---|
| Обычный (Zz) | 5 мин | 5 мин | Сон |
| Кодинг (</>) | Никогда | Никогда | Ничего |

Настройки применяются и от батареи, и от сети. Фоновых процессов нет.

## Установка

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

Создаст ярлык «Режим питания» на рабочем столе. Папку после установки не перемещать (или запустить `install.ps1` заново).

## Файлы

- `toggle.ps1` — переключение через `powercfg` + смена иконки ярлыка
- `toggle.vbs` — запуск без мигания консоли
- `install.ps1` — генерирует иконки и создаёт ярлык
